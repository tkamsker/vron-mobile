  ---
  What the Scripts Do

  AUTH_CODE Encoding

  The scripts automatically encode the access token in the required format:

  {
    "MERCHANT": {
      "accessToken": "<YOUR_ACCESS_TOKEN>"
    },
    "activeRoles": {
      "merchants": "MERCHANT"
    }
  }

  Then base64-encodes it for use in the Authorization: Bearer <AUTH_CODE> header.

  API Headers

  The scripts demonstrate the required headers:
  Authorization: Bearer <AUTH_CODE>
  X-VRon-Platform: merchants
