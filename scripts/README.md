# VRON Mobile - Development Scripts

Collection of shell scripts for development, testing, and deployment workflows.

## Quick Reference

```bash
# First-time setup
./scripts/setup.sh

# Run comprehensive tests
./scripts/test.sh

# Launch on iOS
./scripts/run_ios.sh

# Launch on Android
./scripts/run_android.sh

# Continuous testing (watch mode)
./scripts/watch.sh

# Code analysis
./scripts/analyze.sh

# Clean build artifacts
./scripts/clean.sh
```
