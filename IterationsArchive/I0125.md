  How It Works

  When you complete a scan:
  1. RoomPlan provides walls, doors, and windows data
  2. Thumbnail generator renders a 2D floor plan from this data
  3. Image is saved to disk as PNG
  4. Path is stored in the database with the session
  5. Session list shows the thumbnail to distinguish between scans
